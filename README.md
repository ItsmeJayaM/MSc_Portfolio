# MSc_Portfolio 
This repository contains projects I carried out during my BSc and MSc period. ENJOY!!!

-Engine Ballistics : Space propulsion course team project on characterizing the ballistics of a solid rocket motor
-GE9X : Aerospace propulsion course final project characterizing the GE9X engine from inlet to outlet
-Mission analysis : Mission analysis course team project on orbital transfers
-Orbital Mechanics : Course project on interplanetay transfer with flyby and perturbation study in earth orbit
-Space Systems : Course project on the analysis of ADM-AEOLUS ESA mission. Reverse engineering the mission down to subsystem levels
-Space Propulsion: Course project researching and characterizing different propulsion systems for cubesats
-Attitude Dynamics: Course project involving the modeling and simulation of a GEO Nadir pointing satellite with introduction of kalman observers
